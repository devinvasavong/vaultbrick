## Overview

VaultBrick is a self-hostable, zero-knowledge encrypted data vault designed for businesses transitioning from paper-based records to secure digital storage. It provides military-grade encryption with unique "brick" feature - cryptographic shredding that makes data permanently and verifiably unrecoverable.
